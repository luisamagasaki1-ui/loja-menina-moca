# Loja Menina Moça

Site da Loja Menina Moça, de Pires do Rio – GO: bolsas, eletrônicos, caixas de som, acessórios, mochilas, brinquedos e muito mais.

- Endereço: R. Joaquim Antônio Teixeira, 824 – Centro, Pires do Rio – GO
- Instagram: [@lojameninamocapdr](https://www.instagram.com/lojameninamocapdr/)

O site é uma página única (`index.html`) com as imagens em `img/`. Publicado com GitHub Pages.

Mapa de ruas e satélite (usado só como reserva, quando o Google Maps não carrega): Esri, HERE, Garmin, Maxar, Earthstar Geographics, © colaboradores do OpenStreetMap.
